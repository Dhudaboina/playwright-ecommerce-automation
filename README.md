# Playwright E-Commerce Automation Framework

## 📌 Project Overview

This project is an end-to-end web automation framework developed using Playwright with JavaScript.

The framework follows the Page Object Model (POM) design pattern and includes data-driven testing, HTML reporting, and cross-browser test execution.

## 🛠️ Tech Stack

- Playwright
- JavaScript
- Node.js
- Git
- GitHub
- Page Object Model (POM)
